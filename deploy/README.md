# Размещение пилота на двух облачных серверах Selectel

Текущее состояние созданной инфраструктуры и проверок: [STATUS.md](STATUS.md).

Эта папка готовит схему, в которой сервер данных хранит PostgreSQL и фотографии, запускает API и принимает HTTPS/WSS через Caddy. Второй сервер обрабатывает упражнения. Они соединяются приватной сетью. Кадры упражнений остаются в памяти и не попадают в PostgreSQL.

## Ресурсы для выбора в панели

Обе машины: **Облачные серверы → Shared Line** в одном проекте, регионе и сегменте пула. Не выбирайте продукт VDS. Для первого пилота:

| Назначение | Конфигурация | Сеть |
| --- | --- | --- |
| Данные и API | 2 vCPU по 20%, 2 ГБ RAM, сетевой SSD 40 ГБ | приватный IP, один публичный плавающий IPv4 и облачный роутер |
| Упражнения | 2 vCPU по 20%, 4 ГБ RAM, сетевой SSD 40 ГБ | приватный IP в той же сети, выход в интернет через тот же роутер |

Нужны два адреса одного домена, например `api.example.ru` и `exercise.example.ru`, направленные на публичный IPv4 первой машины. Caddy получает сертификаты автоматически. На первой машине должны быть доступны извне только TCP 80 и 443. Для SSH откройте TCP 22 только со своего адреса. В приватной сети разрешите TCP 8100 от машины упражнений к машине данных и TCP 8000 от машины данных к машине упражнений. PostgreSQL на TCP 5432 не публикуется. В форме Selectel цена публичного IP и роутера добавляется к цене VM; ориентируйтесь на итог справа перед заказом.

## Установка после создания машин

1. Установите Ubuntu 24.04 LTS и Docker Engine с Compose plugin на обе машины.
2. Скопируйте проект на каждую машину, например в `/opt/smile-quest`; достаточно `backend/`, `exercise_server/` и `deploy/`. Файл модели должен быть в `exercise_server/models/face_landmarker.task` на второй машине.
3. На машине данных скопируйте `deploy/data.env.example` в `deploy/data.env`, задайте два **разных** случайных секрета и реальные приватные IP и домены. Пароль БД сделайте из латинских букв и цифр: он используется в URL подключения. На машине упражнений скопируйте `deploy/exercise.env.example` в `deploy/exercise.env` и укажите те же приватные IP.
4. Ограничьте доступ к файлу окружения командой `chmod 600 deploy/data.env` на машине данных и `chmod 600 deploy/exercise.env` на машине упражнений. Не отправляйте секреты в чат и не добавляйте их в репозиторий.
5. Запустите на машине данных:

   ```bash
   docker compose --env-file deploy/data.env -f deploy/data.compose.yaml up -d --build
   ```

6. Запустите на машине упражнений:

   ```bash
   docker compose --env-file deploy/exercise.env -f deploy/exercise.compose.yaml up -d --build
   ```

7. Проверьте `https://api.example.ru/health` и `https://exercise.example.ru/health`, затем запустите сквозной тест с двумя адресами вместо локальных. Flutter-сборке нужны `DATA_API_URL=https://api.example.ru` и `EXERCISE_WS_URL=wss://exercise.example.ru/ws`.

## Данные и расходы

Docker volumes `pg_data` и `photo_data` на машине данных сохраняют базу и фотографии. Настройте в Selectel резервное копирование её сетевого диска по расписанию. Дополнительно делайте `pg_dump` и периодически проверяйте восстановление: копия диска работающей БД сама по себе не заменяет проверенный план восстановления. Ограничьте срок хранения фото и копий в соответствии с политикой приложения.

Для этой конфигурации производительность MediaPipe при нескольких одновременных пользователях ещё не измерена. До приглашения пользователей нужен нагрузочный тест на арендованной машине. Разделение сервисов позволяет отдельно увеличить её ресурсы, но не создаёт реплику PostgreSQL или автоматическое переключение при сбое машины данных.

Оформление поручения на обработку персональных данных и меры защиты самого приложения остаются отдельным этапом перед пилотом с реальными данными пациентов.
