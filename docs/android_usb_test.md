# Проверка упражнений на Android по USB

Публичный сервер и Supabase для этого теста не нужны. Компьютер запускает локальный сервис, а телефон обращается к нему через USB с помощью `adb reverse`. Режим включается только в debug-сборке и показывает семь упражнений с автоматической обработкой.

1. Включите на телефоне «Для разработчиков» → «Отладка по USB», подключите его кабелем и подтвердите разрешение отладки на телефоне.
2. Сначала создайте Python-окружение, установите зависимости и скачайте модель по [инструкции сервиса](../exercise_server/README.md). В первом терминале PowerShell запустите сервис из корня проекта:

   ```powershell
   cd exercise_server
   $env:FACE_LANDMARKER_MODEL = (Resolve-Path .\models\face_landmarker.task).Path
   $env:ALLOW_ANONYMOUS_EXERCISES = 'true'
   .\.venv\Scripts\python.exe -m uvicorn exercise_server.main:app --host 127.0.0.1 --port 8000 --ws-max-size 750000
   ```

3. Во втором терминале PowerShell из корня проекта проверьте телефон и настройте проброс порта:

   ```powershell
   adb devices
   adb reverse tcp:8000 tcp:8000
   flutter run --dart-define=LOCAL_EXERCISE_TEST=true --dart-define=EXERCISE_WS_URL=ws://127.0.0.1:8000/ws
   ```

   Если подключено несколько устройств, добавьте `-d <device-id>` к `flutter run`.

После запуска откроется меню семи упражнений. Разрешите приложению доступ к камере. Компьютер и телефон должны оставаться подключёнными, а терминал с Python-сервисом — открытым. При переподключении USB повторите `adb reverse tcp:8000 tcp:8000`.

Для «Поднятия бровей» сначала нажмите «1. Обычное положение» и спокойно держите брови, пока заполнится шкала калибровки. Затем поднимите обе брови, нажмите «2. Максимальный подъём» и удерживайте их до заполнения шкалы. Нажмите «Начать», опустите брови и повторяйте подъём. Синяя и оранжевая шкалы соответствуют двум сторонам лица; маленькая кнопка отражения вверху меняет только расположение точек, если фронтальная камера показывает зеркальное превью.

После изменений Python-кода остановите уже запущенный сервер сочетанием `Ctrl+C` в его терминале и запустите его снова. Иначе телефон продолжит обращаться к старой версии обработчика.

Если `adb devices` показывает `unauthorized`, подтвердите отладку на телефоне. Если нет устройств, проверьте кабель, драйвер и режим USB. Если приложение показывает ошибку соединения, проверьте `http://127.0.0.1:8000/health` на компьютере и повторите `adb reverse`.

Пороговые значения упражнений пока не проходили проверку на реальных пациентах. Этот запуск предназначен для технической проверки камеры, распознавания и счётчиков.
