# Smile Quest — планшетная версия

Адаптация включается при меньшей стороне окна от **600 логических пикселей**. Поворот телефона в альбомную ориентацию сам по себе не включает планшетный интерфейс.

## Компоновка

- Основные разделы используют постоянную боковую навигацию. Выбранная вкладка сохраняется при повороте.
- Главная, профиль, каталог, зал славы и выбор персонажа используют карточки и сетки с ограниченной шириной содержимого.
- Каталог упражнений показывает выбранное упражнение в отдельной панели на широком экране.
- В фотодневнике календарь и фотографии размещаются рядом в альбомной ориентации; в портретной — последовательно.
- В задачах доступна сетка карточек. Формы, календарь и выбор упражнений ограничены по ширине; клавиатура не перекрывает доступ к полям и кнопкам.
- Авторизация, настройки и прежние экраны получили ограниченный по ширине холст с прокруткой при недостатке высоты.
- В упражнениях 2.0 и фотосъёмке превью сохраняет пропорции **3:4**. На широком экране управление находится рядом с камерой, на узком — под ней.

## Камера

На планшете упражнения не блокируют поворот экрана. Кадр для сервера и кадр для быстрого отслеживания точек используют одинаковый поворот и центральную область 3:4. Точки рисуются поверх видимой области, а ответы, полученные для прежней ориентации, отбрасываются. Поворот прерывает текущее удержание, сохраняя калибровку и уже засчитанные повторы.

Телефонный кодировщик кадров, портретная фиксация камеры, алгоритмы калибровки и подсчёта повторов сохранены. Отдельная ветка обработки геометрии используется только для планшета.

## Проверки

```powershell
flutter analyze --no-fatal-infos
flutter test
```

`test/tablet_layout_test.dart` проверяет экраны на размерах 600×960, 768×1024 и 1280×800, обе ориентации всех инструкций и экранов упражнений без нативной камеры, сохранение вкладки и ввода, увеличение текста до 130%, открытие редактора задач и выбора упражнения. Работа нативного превью проверяется с подставным источником камеры.

`test/tablet_camera_geometry_test.dart` сопоставляет JPEG для сервера и изображение для трекера при четырёх поворотах. Это проверка геометрии; физическую камеру она не заменяет.

`test/mobile_layout_regression_test.dart` сравнивает восемь телефонных экранов 375×812 с эталонами, снятыми до адаптации. Эталоны не обновлялись после изменения интерфейса. Тестовый шрифт Roboto используется только для воспроизводимых метрик текста; лицензия находится в `test/fonts/OFL.txt`.

Проверки на физическом планшете, включая разрешения, аппаратную ориентацию камеры, совпадение точек с лицом и выполнение повторов, ещё нужны. iPad-сборка не выполнялась.
